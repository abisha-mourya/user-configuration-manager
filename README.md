# User Configuration Manager

A beginner Python project completed as part of the freeCodeCamp Python Certification course.

# Description

A user configuration manager that allows settings to be added, updated, deleted, and viewed.

# Concepts Used

- Functions
- Dictionaries
- Tuples
- Conditional statements
- Loops
- String methods
- Dictionary methods
- f-strings

# Features

- Add new settings
- Update existing settings
- Delete settings
- View current settings
- Prevent duplicate settings
- Handle missing settings
